# Once Human Music Bot 🎵

《七日世界》游戏内自动演奏工具，支持吉他和钢琴双模式，通过模拟键盘按键实现 MIDI 文件自动播放。

## 功能特性

- 🎹 **钢琴模式** — 支持完整半音阶（含黑键），使用 Shift/Ctrl 组合键实现高/低音区
- 🎸 **吉他模式** — 22 个白键映射，覆盖常用音域
- 🎛️ **自动适配音域** — 智能分析 MIDI 音高并自动移调到最佳演奏范围
- 🎚️ **播放控制** — 支持调速（0.1x ~ 2.0x）、升降调（±24 半音）、进度拖拽
- ⏯️ **播放/暂停/停止** — 完整的播放控制

## 键位说明

### 钢琴模式

| 音区 | 按键 |
|------|------|
| 低音区 C3~B3 | Ctrl + Q/W/E/R/T/Y/U/2/3/5/6/7 |
| 中音区 C4~B4 | Q/W/E/R/T/Y/U/2/3/5/6/7 |
| 高音区 C5~B5 | Shift + Q/W/E/R/T/Y/U/2/3/5/6/7 |

### 吉他模式

| 音区 | 按键 |
|------|------|
| 低音区 C3~B3 | Z/X/C/V/B/N/M |
| 中音区 C4~B4 | A/S/D/F/G/H/J |
| 高音区 C5~C6 | Q/W/E/R/T/Y/U/I |

## 使用方法

1. 确保已安装 Java 8 或以上版本
2. 编译运行：
   ```bash
   javac music.java
   java music
   ```
3. 点击「选择 MIDI 文件」加载 `.mid` 文件
4. 切换到游戏窗口
5. 点击「开始」，程序会自动倒计时 3 秒后开始演奏

## 目录结构

```
├── music.java          # 主程序
├── midi/
│   ├── 吉他/           # 吉他模式 MIDI 示例
│   └── 钢琴/           # 钢琴模式 MIDI 示例
└── README.md
```

## 注意事项

- 演奏时需要将游戏窗口置于前台
- 程序通过 `java.awt.Robot` 模拟键盘输入，请确保游戏处于可接收键盘输入的状态
- 建议在演奏前关闭其他可能接收键盘输入的程序
