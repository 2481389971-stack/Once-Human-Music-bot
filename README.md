# Once Human Music Bot 🎵

《七日世界》游戏内自动演奏工具，支持吉他和钢琴双模式，通过模拟键盘按键实现 MIDI 文件自动播放。

## 功能特性

- 🎹 **钢琴模式** — 支持完整半音阶（含黑键），使用 Shift/Ctrl 组合键实现高/低音区
- 🎸 **吉他模式** — 22 个白键映射，覆盖常用音域
- 🎛️ **自动适配音域** — 智能分析 MIDI 音高并自动移调到最佳演奏范围
- 🎚️ **播放控制** — 支持调速（0.1x ~ 2.0x）、升降调（±24 半音）、进度拖拽
- ⏯️ **播放/暂停/停止** — 完整的播放控制
- ↺ **一键重置** — 回到刚打开程序的状态（清空已选文件/进度/速度/升降调，见下文）
- 🛡️ **抗错音设计** — 每个音符独立按/松修饰键，长时间连弹不会累积音区错位（见下文「连弹多首后错音」）

## 键位说明

### 钢琴模式

| 音区 | 按键 |
|------|------|
| 低音区 C3~B3 | Ctrl + Q/W/E/R/T/Y/U/2/3/5/6/7 |
| 中音区 C4~B4 | Q/W/E/R/T/Y/U/2/3/5/6/7 |
| 高音区 C5~B5 | Shift + Q/W/E/R/T/Y/U/2/3/5/6/7 |

### 吉他模式

| 音区 | 按键 |
|------|------|
| 低音区 C3~B3 | Z/X/C/V/B/N/M |
| 中音区 C4~B4 | A/S/D/F/G/H/J |
| 高音区 C5~C6 | Q/W/E/R/T/Y/U/I |

## 使用方法

1. 确保已安装 Java 8 或以上版本
2. 编译运行：
   ```bash
   javac music.java
   java music
   ```
3. 点击「选择 MIDI 文件」加载 `.mid` 文件
4. 切换到游戏窗口
5. 点击「开始」，程序会自动倒计时 3 秒后开始演奏

## 一键重置

界面右下角的 **↺ 重置** 按钮可把演奏器恢复到"刚打开程序"的状态：

| 重置内容 | 说明 |
|---|---|
| 已选文件 / 序列 | 清空，状态栏回到「请先选择 .mid 文件」 |
| Sequencer 驻留序列 | 一并清空，避免上一首曲子的残留状态 |
| 播放进度 | 归零并禁用 |
| 播放速度 | 回到 1.0x |
| 升降调 | 回到 0（原调） |
| 乐器模式 | 回到钢琴模式 |
| 自动适配音域 | 恢复默认勾选 |
| 修饰键 | 强制释放 Shift/Ctrl/Alt |

**不受影响**：主窗口尺寸与位置、以及「上次打开的目录」这一便利设置（下次选择文件仍会回到
你上次的文件夹）。演奏期间重置按钮会被禁用——请先「停止」再重置，避免出现边弹边清的中间状态。

## 注意事项

- 演奏时需要将游戏窗口置于前台
- 程序通过 `java.awt.Robot` 模拟键盘输入，请确保游戏处于可接收键盘输入的状态
- 建议在演奏前关闭其他可能接收键盘输入的程序

## 连弹多首后错音（已修复）

**症状**：连续弹奏多首曲子后出现错音（音高不对），重启程序即恢复正常。

**成因**：游戏钢琴被强制分成三个音区，只能用 Shift/Ctrl 切换。旧实现会**跨音符长按修饰键**
（只在音区变化时才切换），程序侧因此保存了一份「以为 Shift 还按着」的状态
（`activeModifier`）。一旦游戏因卡顿、掉帧或输入积压漏掉某次修饰键事件，这份状态就与游戏
真实音区脱钩——此后所有高音区音符都会掉回中音区，听感即「错音」，且**不会自愈**，必须重启
程序把状态归零。弹的曲子越多、音区切换越频繁，越容易命中（本仓库最快的曲子单曲切换超 1200 次）。

**修复**：修饰键不再跨音符保持。每个音符都是一次独立的
「按修饰键 → 按主键 → 松主键 → 松修饰键」，程序侧不再有任何跨音符的修饰键缓存。
即使某个事件偶发丢失，影响也只限于那一个音符，下一个音符会自行重新按下修饰键，
故障半径从「整段错音到曲终」缩小到「单个音符」。同时在开始、暂停、停止、切文件、关窗
五处边界统一强制释放 Shift/Ctrl/Alt。

**已知取舍**：每个带修饰键的音符多两次按键事件（约 25ms 串行耗时，不带修饰约 8ms）。
全库实测总投递耗时仅占谱面时长的 11%，余量充足；密集段落可能出现轻微拖拍。

**观测量**：曲终状态栏会显示实际耗时与谱面长度的差值。若出现
「比谱面慢了 XXX ms」，说明程序在该曲的密集段落跟得吃力，可**降低播放速度**缓解
（速度滑块越低，程序越从容）。

**可选限流**：源码顶部 `MIN_NOTE_GAP_MS` 默认为 `0`（不限流）。设为 20~40 可强制音符最小
间隔，但这会**砍掉同拍的齐奏和弦**（同一时刻的多个音只剩第一个），全库平均仅保留约 63% 的
音符，代价很大，仅在机器性能不足或游戏明显丢键时才建议开启。
